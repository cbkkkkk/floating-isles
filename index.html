【硬性规则，违反就不能上传】
1. 只输出一个文件，包含完整的 <html> 和 <body>，UTF-8 编码，文件小于 2MB。
2. 完全自包含：所有 CSS、JavaScript、图片、字体都内联进这一个文件。
   禁止任何外部 src / href（包括 CDN、unpkg、jsdelivr、/lib/three.min.js、相对路径）。
   不要写 <script src=...>、<link href=...>、<img src="http..."> 这类标签。
3. 可以用「内联的 three.js 完整源码」做 3D，也可以只用原生 Canvas 2D 做二维岛。
   如果用 three.js，请把库源码整个内联进 <script> 标签（window.THREE），
   不要 import、不要 module、不要 fetch。
4. 不要用 window.parent / top / postMessage 访问外层页面，不要读 localStorage 里的
   账号数据，不要弹窗、不要跳转、不要采集访客信息。

【画面与取景约定】
5. 整幅画面就是一座浮空岛：上方是天空，中间是岛顶（草、树、建筑），
   下方是倒锥形岩体和几缕云。主体居中，上方留 25% 左右天空，别把内容顶到边。
6. 岛会被裁成一个圆形窗口显示，且整体缩到约 120px，请保证缩小后仍认得出是岛：
   轮廓清晰、大色块、少细字。背景用深色或透明，不要用整屏纯白。
7. 不要画任何面板、按钮、标题栏、说明文字 —— 那些由外层世界提供。
8. 自适应容器尺寸（监听 resize），动画用 requestAnimationFrame，帧率别拉满。
9. 页面会收到 ?t=0..1 表示时辰（0 子夜 / 0.5 正午 / 0.82 黄昏），
   若方便请让天空和光跟着变化；不处理也可以。

【输出格式】只输出 HTML 源码本身，包在一个代码块里，不要解释、不要拆成多个文件。
